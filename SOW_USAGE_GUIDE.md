# SOW Usage Guide - New Improved System

## 🚀 How to Use the New SOW Generation

### Starting a SOW

Simply type any of these phrases in the unified chat:
- "Create a SOW"
- "Generate a statement of work"
- "I need a SOW document"
- "Generate document"

### Step-by-Step Process

#### 1. Project Information
**Question:** "Let's start with the project basics. Please provide:"
- Document Number (e.g., SOW-2025-001)
- Project Name  
- Key project objectives

**Example Response:**
```
Document Number: SOW-2025-001
Project Name: Healthcare Data Migration
Objectives:
- Migrate patient data to new EHR system
- Ensure HIPAA compliance
- Minimize downtime during transition
```

#### 2. Services Selection
**You'll see two buttons:**
- **Standard Service Package** (Recommended)
- **Custom Services**

**Standard Package includes:**
- Complete Data Extraction, Compression, and Transfer Implementation
- Design Review & Feedback
- Development of Applications (File Transfer mechanism)
- Quality Assurance (Connectivity, SIT, Functional, Non-Functional)
- TDM Coordination
- Pre-Go Live, Go Live, and Post Go Live Support
- 15 detailed scope items

**For Custom Services:**
```
Service 1: Custom API Development
Description: Build REST APIs for data integration
Duration: 4 weeks

Service 2: Database Migration
Description: Migrate legacy database to cloud
Duration: 6 weeks
```

#### 3. Deliverables
**Example Response:**
```
1. HIPAA Compliance Documentation
   Complete documentation ensuring all data handling meets HIPAA requirements

2. Patient Portal Web Application
   Responsive web application for patient data access

3. Mobile Apps (iOS & Android)
   Native mobile applications for healthcare providers

4. EHR Integration Module
   Custom integration with existing EHR systems
```

#### 4. Timeline
**Example Response:**
```
Start Date: 2025-01-15
End Date: 2025-06-30
Total Sprints: 16
Sprint Duration: 2 weeks
```

#### 5. Resources
**Example Response:**
```
- Senior Developer (Development): 2 people, Full-time
- QA Engineer (Testing): 1 person, Full-time  
- DevOps Engineer (Infrastructure): 1 person, Part-time
- Project Manager (Management): 1 person, 50%
```

#### 6. Contacts

**Quick Option - Just mention company name:**
```
Client: WareMax Distribution
Contractor: LogiTech Solutions
```

**Available Companies:**
- **Clients:** WareMax Distribution, SecureBank Financial Group, MUFG Bank Ltd
- **Contractors:** LogiTech Solutions, MobileFirst Technologies Ltd, Oracle Financial Services Software

**Manual Option:**
```
Contractor: John Smith, TechCorp Inc, 123 Tech Street, +1-555-0123, john@techcorp.com, CTO
Client: Jane Doe, HealthSystem LLC, 456 Health Ave, +1-555-0456, jane@health.com, IT Director
```

#### 7. Budget
**Example Response:**
```
Milestone 1: Project Setup and Planning - $25,000
Milestone 2: Development Phase 1 - $50,000  
Milestone 3: Development Phase 2 - $50,000
Milestone 4: Testing and QA - $30,000
Milestone 5: Deployment and Go-Live - $20,000

Estimated Expenses: $5,000
```

#### 8. Document Generation
Once all information is collected, you'll see a **"Generate SOW Document"** button.
Click it to create your professional SOW document!

## 💡 Pro Tips

### 1. Use Standard Services
For most data projects, the Standard Service Package covers everything you need and saves time.

### 2. Leverage Contact Database
Just type the company name instead of full contact details:
- "Client: MUFG Bank Ltd" → Auto-fills all contact information
- "Contractor: Oracle Financial Services Software" → Complete details populated

### 3. Natural Language Works
You don't need to follow exact formats. The AI understands natural language:
- "We need to start January 1st and finish by March 31st with 8 two-week sprints"
- "Budget is 100k split into 4 milestones of 25k each"

### 4. Edit and Iterate
You can always go back and modify information during the conversation.

### 5. Exit SOW Mode
Click the "Exit SOW" button anytime to return to general chat mode.

## 🎯 What You Get

- Professional formatting

## 📞 Support

If you encounter any issues:
1. Check that all required information is provided
2. Try rephrasing your input in natural language
3. Use the Exit SOW button to restart if needed
4. Contact the development team for technical issues
